# **App Name**: Doodle AI

## Core Features:

- Drawing Canvas: Interactive canvas for freeform drawing.
- Analyze Button: Button to trigger AI analysis of the drawing.
- AI Image Guess: AI-powered tool that interprets the canvas and guesses what the drawing represents.
- Guess Alert: Alert modal that displays the AI's guess.
- Smiley Background: Background using a mosaic of smiley face doodles.

## Style Guidelines:

- Primary color: White (#FFFFFF) for clean canvas look.
- Accent color: Blue (#3498db) for button highlights.
- Use a clear and legible font for any text elements.
- Simple and intuitive layout for easy doodling.
- Subtle animation feedback on AI analysis button click.
- Use simple, recognizable icons for drawing tools (e.g., pencil, eraser).
